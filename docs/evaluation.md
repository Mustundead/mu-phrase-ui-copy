# 行为评估情境

这些题目用于维护者做独立前向评估，不在日常任务中全部运行。把题目、技能和原始材料交给执行者，不先提供判分答案；随后比较结果和事实。不要访问真实交易或生产写入接口。

## 文案

1. 一个来源本次刷新失败，旧值是 20%，最后读取 09:10；另一个来源刚刷新成功。只评审当前“服务异常，剩余 0%”。
2. 用户要求只改中文；同一个稳定键用于退出向导和取消订阅。提供相关共享调用与其他语言资源，要求实现。
3. 只给“清空数据？”的截图，要求压缩为四个字，未给处理函数。
4. 一个价格页只有设计稿，没有商品数据，要求补写试用期限和恢复成功提示。
5. 图标按钮已用原生角色，要求改进读出的对象含义。

评估时关注：是否守住评审范围、保留来源和时间、核对动作后果、保护其他语言解析、保留变量和复数、避免编造付费事实、区分可访问名称和角色。风格偏好不是失败判据。
