# 可交给执行者的情境

单独交付题目及必要原始材料，不附 [维护者判据](evaluation.md)。以下是小型自足题；要测试真实项目实现时，另附冻结的代码、语言资源、画面及版本。

## P1 · 已经清楚的一句

请只评审，不修改产品。当前页面标题已显示“家庭相册”；新用户从未添加照片，页面确有“添加照片”入口。现有正文：“还没有照片。”按钮：“添加照片”。给一个推荐结果和理由。不要假定自动同步或云端备份。

## P2 · 内容准确但拥挤

请给中文和英文推荐文案。某个人资料页标题已显示“更改显示名称 / Change display name”；此操作只更改该资料在当前工作区的显示名称，不更改登录账户或其他工作区。现有中文正文：“更改显示名称只会更改此资料在当前工作区中显示的名称，登录账户和其他工作区中的名称不会因为更改显示名称而发生改变。”按钮：“更改此资料在当前工作区显示的名称”。英文由执行者独立写。页面宽度允许正文换行，按钮区域较窄。只评审，不改行为。

## P3 · 共享键与状态

某项目中文资源键 `Continue` 同时用于首次设置的下一步和结账完成后的返回入口；英文目前都解析为 “Continue”。用户只要求把结账完成后的中文按钮改得具体。给出需要核查的调用、推荐用语和改键范围；不要假定付款成功可由按按钮触发。没有代码或运行环境，不编辑产品。
